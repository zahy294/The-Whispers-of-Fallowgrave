# The-Whispers-of-Fallowgrave
The Whispers of Fallowgrave is an atmospheric, choice-driven narrative game where you play as a weary investigator drawn to a fog-choked town with a missing girl, a frantic father, and a story you may have lived before.
Through branching choices, sanity mechanics, ambient audio, and dynamic scene backgrounds, you uncover clues, confront distorted memories, and eventually face the truth:
You are not here to solve the crime — you are here to remember it.

Features

   -Sanity system affecting visuals and narrative tone

   -Branching story scenes with meaningful consequences

   -Clue & Inventory tracking that unlocks paths and reveals the truth

   -Dynamic atmospheric backgrounds with subtle horror imagery

   -Ambient audio and sound effects tied to scene transitions

  - Mirrors, memory loops, unreliable narrative framing

  - Fully contained in HTML / CSS / JS (no engine required)

Tech Stack

  -HTML5

  -CSS3 (custom UI + atmospheric styling)

  -Vanilla JavaScript (state handling, scene system, UI rendering)

  -Pure browser-based – no frameworks, no dependencies

How to Play

  -Download or clone the repository

  -Open index.html in any modern browser

  -Choose your path, follow the clues, and try to keep your sanity

Content Warning

  -This game contains themes of psychological distress, memory loss, and implied violence.
